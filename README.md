# Insurance Fraud Detection Prototype

This project is a machine learning prototype developed in partial fulfilment
of the requirements for a Master's degree in Software Engineering.

## Overview
The system trains fraud detection models using Jupyter Notebook (Anaconda)
and deploys the selected model using a Streamlit web application.

## Technologies
- Python
- Scikit-learn / XGBoost
- Jupyter Notebook
- Streamlit

## How to Run
1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Run the app:
   streamlit run app.py

## Notes
This prototype is intended for academic and research purposes.
